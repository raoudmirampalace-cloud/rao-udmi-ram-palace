1. Download and extract this ZIP.
2. Open https://github.com/raoudmirampalace-cloud/rao-udmi-ram-palace
3. Click Add file > Upload files.
4. From the extracted folder, select index.html, rurp-logo.jpg, entrance.jpg, stage.jpg, night-entrance.jpg (and optionally rurp-logo.svg). Select the files themselves, not their containing folder.
5. Scroll down and Commit changes to main. Replace the existing files when prompted.
6. Wait 2–5 minutes. Open https://raoudmirampalace-cloud.github.io/rao-udmi-ram-palace/ and press Ctrl+F5.

The previous entrance image was WebP data with a .jpg extension. This package fixes that by creating a genuine JPEG.
